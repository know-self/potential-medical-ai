# Terminal commands

- `/help`: show help
- `/new`: reset in-memory history and selected attachments
- `/status`: inspect gateway and knowledge freshness
- `/history`: print current terminal history
- `/attach <path>`: upload evidence using the current user session
- `/attachments`: list selected evidence IDs
- `/detach <id|all>`: update attachment selection
- `/token <value|clear>`: set or clear the in-memory user session token
- `/context`: read consented patient context
- `/save [path]`: explicitly save history without the session token
- `/load <path>`: load a saved terminal session
- `/exit`: quit
